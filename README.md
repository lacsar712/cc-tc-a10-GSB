# 隧道收敛测缝台

测量员登记里程桩号与收敛毫米值。接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

通车窗打开时可在「通车快照」专页填窗口名称点快照，把当时还在路上（待办 `pending` / 在办 `processing`）的测缝单**编号、断面（桩号）、毫米**整份抄进快照库，供监理日后回看。

## 快照规则

- 入口在页眉「通车快照」专页；明细固定三栏：编号 / 断面 / 毫米。
- 仅测量员（writer）可点快照；巡检（reader）能查阅历史与明细，但看不到点快照入口（接口同样 403 拒绝）。
- 快照头（窗口名称、点快照人、时间）与明细**同一事务一次提交**，失败整体回滚，不存在只写了半截的快照；快照不允许零明细。
- 明细是值副本（不挂在线单据外键）：快照落成后，在线单据再办结、改状态或改桩号，都**不会回写**快照，新旧两套始终分清。
- 点快照时一把行锁锁定全部在途单据，认领线程在提交前无法办结其中任何一笔，保证抄入集合与那一瞬间的在途集合完全一致（在途三条则三条齐）。
- 窗口名称唯一，重复点同名窗口返回 409，不覆盖旧快照。
- 单据状态：`pending`（待办）→ `processing`（在办，已认领待出结论）→ `done`（办结）；只有前两者算在途。

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/snapshots` | 登录 | 历史快照列表（含在途笔数） |
| GET | `/api/snapshots/<id>` | 登录 | 单份快照头 + 明细 |
| POST | `/api/snapshots` | 测量员 | 入参 `{"window_name": "..."}`，原子落库 |

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16
